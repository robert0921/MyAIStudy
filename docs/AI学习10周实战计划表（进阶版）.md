# 🧭 AI学习10周实战计划表（进阶版）

## 🧩 阶段一：深度学习与数学内核（第 1~4 周）

> 🎯 目标：从“会用框架”变成“理解框架原理的人”。

| 周次    | 学习重点                                  | 实践与输出                                |
| ----- | ------------------------------------- | ------------------------------------ |
| 第 1 周 | 复习线性代数、矩阵运算、自动微分机制（重点：Jacobian 与链式法则） | 使用 NumPy 手写线性层和 ReLU 激活              |
| 第 2 周 | 理解反向传播（手推公式 + 实现）                     | 手动计算 2 层网络梯度，与 PyTorch autograd 对比   |
| 第 3 周 | 优化算法：SGD、Adam、RMSProp 数学原理            | 对比不同优化器在 MNIST 上的收敛曲线                |
| 第 4 周 | 卷积与 Transformer 基础                    | 手写 CNN & self-attention 模块，理解矩阵乘法的意义 |

> ✅ 输出成果：
>
> * 一篇技术博客：《从零实现反向传播机制》
> * 一份 Colab 笔记：NumPy 实现 Mini-Transformer

---

## ⚙️ 阶段二：工程级模型与高效训练（第 5~8 周）

> 🎯 目标：从“能训练模型”到“能优化模型与资源利用”。

| 周次    | 学习重点                                   | 实践与输出                            |
| ----- | -------------------------------------- | -------------------------------- |
| 第 5 周 | PyTorch 模型模块化、数据管线（Dataset/DataLoader） | 重构 Kaggle 模型结构，优化 IO 性能          |
| 第 6 周 | 模型调优策略：学习率调度、早停、BatchNorm、Dropout      | 复现 CIFAR-10 竞赛模型，记录准确率与显存占用      |
| 第 7 周 | 模型压缩与量化（Pruning / Quantization）        | 比较压缩前后模型精度变化（Top-1 Accuracy ±1%） |
| 第 8 周 | 分布式训练与混合精度                             | 在单机多卡上跑 DDP + FP16，记录吞吐量变化       |

> ✅ 输出成果：
>
> * 模型压缩实验报告
> * 性能指标表（显存占用、吞吐量、精度曲线）

---

> 🎯 目标：理解并掌握大型语言模型底层机制、提示工程。

> ✅ 输出成果：

> * Prompt Engineering 实验日志
