# 🧭 初级AI学习路线（入门阶段 · 12周）

## 🎯 核心目标

> 从“有编程基础但不熟悉Python” → “掌握Python、AI基础理论与实战能力，可衔接进阶计划”。

---

## 阶段结构概览

| 阶段   | 时间范围      | 学习目标                | 输出成果                         |
| ------ | ------------- | ----------------------- | -------------------------------- |
| 阶段 1 | 第 1~4 周     | Python 与数据科学生态    | 熟练使用 NumPy、Pandas、Matplotlib |
| 阶段 2 | 第 5~8 周     | 机器学习基础与 Scikit-Learn | 完成分类/回归/聚类项目            |
| 阶段 3 | 第 9~12 周    | 深度学习入门与 PyTorch   | 实现 CNN、RNN 图像与文本分类项目  |

---

## 🐍 阶段一：Python 与数据科学基础（第 1~4 周）

> 🎯 目标：掌握 Python 语法、数据处理与可视化能力。

| 周次   | 学习重点                               | 实践与输出                             |
| ------ | -------------------------------------- | -------------------------------------- |
| 第 1 周 | Python 基础语法、函数、类、模块          | 实现一个学生成绩管理系统（面向对象）       |
| 第 2 周 | NumPy 数组操作、广播机制、矩阵运算        | 实现图像灰度化、矩阵乘法等基础操作         |
| 第 3 周 | Pandas 数据处理：读取、清洗、分组、合并   | 分析某电商用户行为数据（如订单量、复购率） |
| 第 4 周 | Matplotlib / Seaborn 可视化            | 绘制销售趋势图、热力图、分布图           |

> ✅ 输出成果：
>
> - 一篇博客：《从C++到Python：我遇到的10个语法差异》
> - 一个数据分析项目报告（含代码与图表）

---

## 📊 阶段二：机器学习基础与 Scikit-Learn（第 5~8 周）

> 🎯 目标：理解机器学习基本流程与常用模型，能独立完成建模任务。

| 周次   | 学习重点                               | 实践与输出                             |
| ------ | -------------------------------------- | -------------------------------------- |
| 第 5 周 | 机器学习基础：监督/无监督学习、评估指标     | 使用 Scikit-Learn 完成鸢尾花分类任务    |
| 第 6 周 | 线性回归、逻辑回归、决策树               | 预测房价 / 用户流失分类项目             |
| 第 7 周 | 聚类算法：K-Means、DBSCAN               | 对用户进行分群分析                     |
| 第 8 周 | 模型调优：交叉验证、网格搜索、特征工程     | 优化模型并提交 Kaggle Titanic 比赛结果  |

> ✅ 输出成果：
>
> - Kaggle Titanic 比赛提交记录（Top 50%）
> - 模型调优实验笔记（Notion / 博客）

---

## 🧠 阶段三：深度学习入门与 PyTorch（第 9~12 周）

> 🎯 目标：掌握深度学习基础，能用 PyTorch 实现图像与文本分类任务。

| 周次    | 学习重点                               | 实践与输出                             |
| ------- | -------------------------------------- | -------------------------------------- |
| 第 9 周  | PyTorch 基础：Tensor、自动微分、Dataset | 手写数字识别（MNIST）项目               |
| 第 10 周 | CNN 原理与实现                          | 实现 CIFAR-10 图像分类模型              |
| 第 11 周 | RNN / LSTM 基础                         | 文本情感分类任务（IMDB 数据集）         |
| 第 12 周 | 综合项目：从数据加载到模型部署（简易版）   | 搭建一个网页端手写数字识别应用（Gradio）|

> ✅ 输出成果：
>
> - 图像与文本分类项目代码（GitHub）
> - 一篇总结文：《我的第一个深度学习项目：从0到1》

## 💡 总体建议

- **每周写小结**：记录“学到的知识点 + 遇到的坑 + 解决方式”。
- **动手优先**：每个知识点配套一个小脚本或项目。
- **社区互动**：在 Kaggle / GitHub 上 fork 项目，学习他人代码。
- **可视化进度**：用 Notion 或 Excel 记录每周完成情况，形成学习地图。
